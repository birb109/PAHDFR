# PAHDFR

**Provenance-Aware Historical Digital Footprint Reconstruction: A Temporal OSINT Framework with Evidence Correlation and Reproducible Evaluation**

This project develops an integrated workflow for discovering and preserving historical web artifacts, analyzing content changes, correlating entities and temporal evidence, and producing provenance-linked historical timelines that can be evaluated reproducibly.

The listed technology stack is a proposed system design; it does not imply that every component is implemented or installed in this repository.
